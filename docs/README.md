# Documentation

This folder contains the project documentation split by topic instead of keeping everything in the root `README.md`.

The pages here describe the live runtime, build, and generator contracts of this child theme rather than generic WordPress theme guidance.

- build tooling: [PostCSS Pipeline Deep Dive](./build-and-tooling/postcss-pipeline.md), [CLI And Generators](./build-and-tooling/cli-and-generators.md), and [AI Guidance And Skills](./build-and-tooling/ai-guidance.md)
